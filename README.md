### 1. Постановка задачи
  > Программа получает на вход 2 числа a и b, нужно решить неравенство, вида $\frac{a}{x(x-b)} \geq 0$ для x.
Данную задачу можно решить методом интервалов. Для определения знака дроби необходимо знать знак числителя a и расположение точек 0 и b на числовой прямой. Поэтому необходимо рассмотреть знаки чисел a и b.

Каждое из чисел a и b может быть отрицательным, положительным или равным нулю. Таким образом, всего необходимо рассмотреть 3 * 3 = 9 случаев.

### 2. Входные и выходные данные

#### Данные на вход

На вход программа должна получать 2 числа, при этом в условии не сказано, к какому множеству
принадлежат получаемые числа, поэтому будем считать их вещественными.

|             | Тип                |min значение   |max значение  |
|-------------|--------------------|---------------|--------------|
| a (Число 1) | Вещественное число |-10<sup>9</sup>|10<sup>9</sup>|
| b (Число 2) | Вещественное число |-10<sup>9</sup>|10<sup>9</sup>|

#### Данные на выход

Т.к программа решает неравенство то на выход мы должны получить объединение интервалов.

|         |  Тип   |   решение неравенства   |
|---------|--------|-------------------------|
| Строка1 | строка | "множество значений x"  |

### 3. Выбор структуры данных

Программа получает 2 вещественных числа. Поэтому для их хранения
можно выделить 2 переменных (`a` и `b`) типа `double`.

|             | название переменной | Тип (в Java) | 
|-------------|---------------------|--------------|
| a (Число 1) | `a`                 | `double`     |
| b (Число 2) | `b`                 | `double`     | 

Для вывода результата необязательно его хранить в отдельной переменной.

### 4. Алгоритм

#### Алгоритм выполнения программы:

1. **Ввод данных:**  
   Программа считывает два вещественных числа, обозначенные как `a` и `b`.

2. **Проверка знаков:**  
   Программа рассматривает все 9 вариантов знаков чисел `a` и `b`:

   - `a = 0, b = 0`;
   - `a = 0, b > 0`;
   - `a = 0, b < 0`;
   - `a > 0, b = 0`;
   - `a > 0, b > 0`;
   - `a > 0, b < 0`;
   - `a < 0, b = 0`;
   - `a < 0, b > 0`;
   - `a < 0, b < 0`.

3. **Вывод результата:**  
   На экран выводится интервал, соответствующий набору чисел `a` и `b`.

### 5. Программа
```
import java.io.PrintStream;
import java.util.Scanner;

public class Main {
    // Объявляем объект класса Scanner для ввода данных
    public static Scanner in = new Scanner(System.in);
    // Объявляем объект класса PrintStream для вывода данных
    public static PrintStream out = System.out;
    
    public static void main(String[] args) {
        // Считывание двух вещественных чисел a и b из консоли
        double a = in.nextDouble();
        double b = in.nextDouble();
        
        if (a == 0){
            if (b == 0) out.printf("x < 0 or x > 0");  // случай для a = 0, b = 0
            else{
                if (b > 0) out.printf("x < 0 or 0 < x < %s or x > %s", b, b); // случай для a = 0, b > 0
                else out.printf("x < %s or %s < x < 0 or x > 0", b, b); // случай для a = 0, b < 0
            }
        }
        else{
            if (b == 0){
                if (a > 0) out.printf("x < 0 or x > 0"); // случай для a > 0, b = 0
                else out.printf("no such x"); // случай для a < 0, b = 0
            }
            else{
                if (a > 0){
                    if (b > 0) out.printf("x < 0 or x > %s", b); // случай для a > 0, b > 0
                    else out.printf("x < %s or x > 0", b); // случай для a > 0, b < 0
                }
                else{
                    if (b > 0) out.printf("0 < x < %s", b); // случай для a < 0, b > 0
                    else out.printf("%s < x < 0", b); // случай для a < 0, b < 0
                }
            }
        }
    }
}
```
